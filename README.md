Box2D 是用于游戏的二维物理引擎。

## 当前能力

当前可以检查 C17 与 C++20 工具链，并用 CTest 运行测试。程序可以查询库版本 3.2.0 和双精度设置，也可以安装、触发并恢复断言回调，使用默认输出或用户日志回调记录消息，设置每米长度单位，以及按 64 字节对齐分配和释放内存。长度单位只接受有限正数，非法值保持原值。分配统计会在释放后回到原值，也可以换成自定义分配器。扩容时保留已有内容。清零分配得到全零内存，清零扩容只清零新增区间。可以判断浮点数是否为有限值，并计算整数与浮点数的最小、最大、绝对值和夹紧。二维向量支持加减、点积、叉积、长度和归一化。旋转可以组合、求逆，并保持单位长度条件。坐标变换支持点和向量在局部与世界之间往返。2×2 矩阵可以乘向量、求逆，并求解可逆与退化的线性方程。角度使用确定性的正弦、余弦、反正切和折返。动态数组带有 data、count、capacity，创建和销毁成对释放内存。容量可以预留和按两倍增长，已有内容保持不变。追加和原位追加在扩容前后都保留内容，也可以追加数组自身的元素。可以按下标读取元素，常量和非常量访问结果一致。尾部弹出按后进先出返回元素，剩余长度随之减少。交换删除会把末尾元素搬到被删位置，删除末尾时返回空索引。调整长度时缩小保留前缀，扩大保留已有值，清零调整会把范围内的元素写成零，清空只把长度归零并保留容量。创建、销毁和预留只接受平凡且标准布局的元素，元素对齐不超过 64 字节。值交换使用值临时变量，交换数组元素和指针时不会把同一侧的新值写回去。位集合可以创建和销毁，设定有效位数后可以设置、清除和读取指定位，范围外读取为假。扩容会保留已有位，并集把另一组相同长度的位并入当前集合。ID 池在空闲列表耗尽时发放新编号，释放后按后进先出复用，未释放的编号不会进入空闲列表。哈希集合的容量至少为 16 并向上取整到 2 的幂。插入已有键不会增加计数，哈希到同一槽的不同键沿探测链保存，两者都能找到。删除探测链中间或跨越表尾的键后，其余键仍然可以找到，不存在的键删除失败且计数不变。计数达到容量的一半时容量翻倍，原有键在新表中仍然可以找到，重复插入不改变计数。临时栈按 64 字节对齐分配，必须以后进先出释放。放不下的请求改为单独堆分配，全部释放后高水位仍保留，空闲时按高水位的一点五倍扩大容量。可以读取系统时钟，并计算从某个计数值到当前时刻经过的毫秒数，也可以在读取后把计数值重置为当前时刻。轴对齐包围盒可以检查上下界是否有效，计算中心、半尺寸、重叠和并集。边界相接算重叠，上界小于下界或含有非有限值则无效。射线可以命中包围盒的边和角，给出法线、命中点和比例。起点在内部、方向平行且落在盒外、线段太短或长度为零时不命中。比例恰好为 1 的边界命中有效。圆由中心和半径表示，半径可以为 0，但不能为负或非有限值。线段由两个有限端点表示，两端重合仍然有效。胶囊由两个端点圆心和半径组成。两端重合或半径为 0 仍然有效，负半径和非有限端点无效。点集可以算出逆时针凸包。内部点、过近的重复点和边上的共线点不会留下，全部共线、少于 3 个点或超过 8 个点时得到空凸包。顺时针或共线的结果不能通过校验。凸包可以做成多边形，复制顶点、写出外侧法线并计算质心。盒子和正方形是原点处的基本凸形状。空凸包会得到边长为 1 的正方形。多边形可以平移和旋转，圆角只增加半径、不改顶点。旋转后外侧法线跟着转动，质心落在变换后的位置。空凸包做偏移时仍得到原点处的单位正方形。圆的质量等于密度乘以面积，质心在圆心，绕质心的转动惯量是质量乘以半径平方的一半。胶囊质量由两端圆和中间矩形组成，质心在两端中点，两端重合时结果与同半径的圆一致。多边形质量由三角形积分得到，平移后质量与绕质心的惯量不变、质心跟着移动。单顶点和双顶点分别按圆和胶囊计算，圆角会增大质量。圆、胶囊、多边形和线段可以在给定变换下算出包围盒，多边形半径会把盒子向外扩大。点在圆内、圆上或圆外可以区分，半径为零时只有圆心算在里面。胶囊的中段和两端半圆都参与包含判断，两端重合时与同半径的圆一致。凸多边形在边界上算包含，平移和旋转后仍按变换后的边判断。圆角沿边向外扩展，对角顶点外侧要按到顶点的距离判断。射线与圆相交时给出命中点、外向法线和沿位移的比例。射线打不中、比例不够或从圆外发出的零长度射线都不命中；起点已经在圆内则记为命中。胶囊射线可以打中侧面或任一端帽，两端重合时与圆的结果一致，从内部发出时停在起点。线段射线可以只接受正面，也可以两面都接受。交点落在端点上算命中，超出端点、平行或打到重合端点的线段则不命中。半径为零的多边形射线会给出进入的边、法线和比例；打不中时没有交点，起点已经在多边形内则停在起点。两条线段可以求最近点：相交时距离为零，平行时保持间距，最近点会夹在端点上，退化成点时退回点到线段的距离。距离代理保存一份点的副本和半径，超过 8 个点时只保留前 8 个。带偏移的代理会先平移和旋转这些点。两个凸形状可以用 GJK 求最近点和距离。第二次查询可以复用上一次的单纯形缓存。形状重叠时距离为零。打开半径后，距离会减去两边的半径，最近点落在圆周上。形状 B 的位姿会先变到形状 A 的坐标系里。形状可以沿直线扫掠。相向移动时给出命中比例和法线，背向移动或比例不够时不命中。一开始就重叠时命中比例为零。圆、胶囊、线段和多边形都可以作为被扫掠的目标，各自把几何交给同一次形状扫掠。扫掠变换按时间插值质心和旋转，并把位置从质心移回局部中心。两个运动形状可以求出首次碰撞时间。相向移动时给出命中时刻和法线，背向离开时保持分离，一开始就重叠时时刻为零。两个圆在穿透、刚好接触和轻微分离时生成一个接触点，法线从第一个圆指向第二个圆。分离超过预测距离时没有接触点。胶囊与圆的接触会落在中段或某一端帽上，远离时没有接触点。多边形与圆可以在边上、顶点上或圆角外接触，圆心在多边形内时分离量为负，离得够远时没有接触点。两条平行胶囊在重叠的一侧给出两个接触点，端点相对时给出一个接触点，离得够远时没有接触点。线段与圆两侧都能接触，端点外按到端点的距离计算，离得够远时没有接触点。线段与胶囊在两侧重叠时各给出两个接触点，端点相对时给出一个接触点，离得够远时没有接触点。多边形与胶囊在边上给出两个带特征标识的接触点，靠近端点时仍有接触，带圆角时把半径算进分离量，离得够远时没有接触点。两个多边形边对边重叠时给出两个接触点，特征标识不同且重复计算保持不变，圆角计入分离量，离得够远时没有接触点。线段穿过多边形时分离量为负，离得够远时没有接触点。链段只在右侧与圆接触，落在相邻边区域内或离得够远时没有接触点，转角外侧仍由当前链段负责。链段与胶囊同样只在右侧接触，下一段负责的一侧没有接触点，当前段的端点附近仍有接触。链段与多边形在平滑连接处保持边法线，凸角外侧的幽灵碰撞会被丢掉，背面没有接触点。相邻多边形可以焊成闭合链条，共享边会抵消，T 形连接并进外轮廓，角点相触和完全重叠会标出状态，释放后链条内存成对归还。空的动态树可以创建和销毁，销毁后分配字节数回到创建前，销毁空指针没有影响。插入代理后可以读回包围盒和用户数据，已有代理的数据保持不变。删除一个代理后其余代理仍然有效，空出的编号会再次发给新代理，全部删除后计数回到零。移动代理会换成新的包围盒，扩大代理会改成更大的范围，旁边的代理保持原样。每个代理有自己的类别位，修改一个不会改到另一个。重建之后代理数量、包围盒和用户数据保持不变，父子包围盒仍然包含子节点。标记移动的代理可以被收集出来，重拟合之后根包围盒包住新的范围。包围盒查询的命中与逐个比较一致，类别掩码可以排除不匹配的代理。射线查询命中最近的包围盒，结果与逐个求交一致，打不中时没有代理。包围盒扫掠命中最近的代理，分数与扩大后的求交一致，扫空时没有代理。树可以报告高度、面积比、根包围盒和实际占用的字节数。可以创建和销毁空世界，非法重力不会占用世界槽，销毁后分配回到原值。空编号、越界编号和已销毁编号都无效，槽位复用后旧编号仍然无效。世界用户数据可以写入并读回，另一个世界不受影响。可以按默认定义创建和销毁刚体，非法位置不会占用槽位，世界销毁后分配回到原值。刚体槽位复用后旧编号仍然无效，销毁世界后该编号也无效。刚体名称最长 10 个字符，用户数据可以写入并读回，另一个刚体不受影响。失败断言的回调返回 0 时不会进入调试中断。当前世界只提供无接触的自由运动，尚无碰撞响应。

## 刚体姿态

可以读取刚体位置、旋转和世界变换，并在局部与世界坐标之间转换点和向量。点转换包含平移，向量转换只包含旋转。可以设置刚体的位置和旋转；非法输入保持原状态，后续查询立即反映有效变换。

刚体可以挂接和销毁圆形、胶囊、多边形、线段，形状使用独立且可复用的稳定编号。包围盒合并已挂接形状的预测性范围；没有形状时返回包住刚体原点的零尺寸范围。修改变换会同步形状范围，销毁刚体会销毁其全部形状。支持按密度计算刚体质量、复合质心和绕质心惯量，也可延迟更新后显式从形状重算。静态刚体质量为零，旋转锁定使惯量为零。传感器和碰撞响应尚未接入。

形状用户数据可以在创建时写入，也可以独立设置和查询；过期形状编号不会改到复用后的对象。

可以读取形状类型和几何数据，并在圆、胶囊、多边形与线段之间修改几何。修改保留形状编号和用户数据，包围盒立即更新。

可以显式设置刚体质量、局部质心与惯量，之后也可以从形状恢复计算值。非法质量数据保持原状态，旋转锁定优先于指定惯量。

支持闭合链和具有显式幽灵端点的开放链。链复制顶点和材质，拥有其链段；销毁链、刚体或世界都会释放链段与索引。链段不能单独销毁。

可以按链的原始顺序枚举链段，读取相邻幽灵顶点，查询链所属世界和形状父链；输出容量不足时只写入可容纳的条目。

链支持逐段材质或整链批量材质设置，合法值会复制到链段，非法值保持原材质。

可以查询刚体所属世界、形状所属刚体和世界，并按容量枚举刚体形状；枚举反映当前链表及删除结果。

每个世界独立管理静态、运动学和动态三棵广相位空间树，按形状容量配置创建并随世界释放。

启用刚体上的形状会在所属类型空间树中创建代理，保存类别位、形状下标和保守范围；销毁形状或刚体会移除代理，禁用刚体不创建代理。

刚体变换超过保守范围时会移动树代理并标记更新，小幅移动保留原保守范围。修改形状几何会重建对应代理；禁用形状仍只更新几何范围。

单线程广相位使用双树遍历、跨树种子和已移动兄弟节点生成候选形状对，覆盖动态与静态、运动学及动态自身。当前只输出原始候选，不创建接触或施加碰撞响应。

候选收集会排除已有形状对集合中的键；移除已有键并重新标记代理后，该对可以再次报告。

候选形状键通过八位分桶的 LSD 基数排序得到确定性顺序，包含全宽 64 位键和重复键。

候选过滤会排除同一刚体上的形状，使用双向类别掩码和正负组索引规则，并排除没有流形算法的边与边配对。运行时更改过滤器会同步树类别和移动标记。

无接触步进使用当前线速度和角速度分子步积分，统一写回质心、姿态和代理。动态刚体具有正逆质量时施加重力，支持独立重力缩放；线性与角阻尼使用每子步的 Padé 系数；可以累加外力，偏心施力产生力矩；每子步按逆质量和逆惯量积分，并在完整步进后自动清除，也可主动清除。

可以设置和读取线速度、角速度，并查询局部点或世界点处的速度。静态与没有活动状态的刚体返回零速度；旋转分量按到质心的偏移计算。

可以独立累加力矩；只作用于启用的动态刚体，并遵循显式唤醒参数，步进后与外力一并清除。

线性冲量立即改变速度，偏心冲量同时改变角速度；质心冲量不产生额外转动，线速度遵循当前上限。

角冲量按逆惯量立即改变角速度；旋转锁定的零逆惯量使角冲量无效。

目标变换通过质心位移和相对角度计算速度，不直接传送刚体；遵循禁用、静态、唤醒与休眠阈值规则。

静态刚体不运动，运动学刚体按指定速度运动且不受重力和外力，动态刚体按质量响应重力与外力。创建时拒绝越界类型，可查询当前类型。

运行时切换刚体类型会同步质量和代理树；经过静态类型的活动状态重建时速度归零，动态与运动学之间保留已有速度。禁用刚体切换类型不创建代理。

广相位重叠会创建具有稳定编号的接触对象，并接入两侧刚体的双向关联。范围分离、形状或刚体销毁、类型和过滤改变会移除接触。接触使用已有配对算法更新流形，法线位于世界坐标系，锚点相对两侧质心；此阶段尚未施加碰撞响应。

流形按接触点特征 ID 匹配上一帧，保留法向、切向和滚动冲量。每次更新重置本步累计冲量和法向速度，失去接触后不会继续携带旧点冲量。

公开查询可以按接触编号读取流形，或按刚体、形状枚举实际接触的数据。容量为保守上界，非接触的广相位对象不会出现在接触数据中，输出遵循调用者容量。

刚体管理句柄与仿真数据分开存储，静态、禁用、活动和休眠集合各自管理连续仿真数组。只有活动集合有速度状态；交换删除、类型迁移和唤醒会修正所属索引及关联接触索引。

## 构建

需要 CMake 3.22 或更高版本，以及支持 C17 和 C++20 的编译器。

```powershell
cmake -S . -B build-core -G "Visual Studio 17 2022" -A x64
cmake --build build-core --config RelWithDebInfo --parallel 8
.\build-core\bin\RelWithDebInfo\toolchain_check.exe
ctest --test-dir build-core -C RelWithDebInfo --output-on-failure --no-tests=error
```

工具链程序通过时打印 `C17 and C++20 toolchain check passed` 并返回 0。CTest 会运行 `unit_tests`。

接触岛按非静态刚体的连通性合并，移除约束后使用并查集拆分；静态地面不连接独立的岛。刚体创建、类型变更、销毁和唤醒同步维护岛与求解集合索引。

触碰接触进入持久约束图，按颜色位集合避免动态体端点冲突，并保留高连接数的溢出路径；结束触碰和销毁同步移除，交换删除修正接触索引。

世界步进从约束图准备标量接触约束，缓存当前质量、转动项、锚点、法线和初始分离；临时约束按栈顺序分配与释放。

法向接触约束现在产生真实碰撞响应：累积冲量保持非负，仅改变动态体速度，并在每个子步的速度与位置积分之间求解。

每帧求解结束将法向冲量和该帧总法向冲量写回持久接触缓存，可由接触查询读取，并供后续帧的接触匹配保留。

每个接触子步按速度积分、软偏置推开、位置积分、无偏置松弛顺序推进；分离包含锚点旋转和位置增量，推开速度受配置上限约束。

接触热启动默认开启，可通过世界接口切换。准备阶段按开关加载持久法向冲量，每个子步施加缓存后继续求解；静态和运动学体不会被缓存冲量修改。

世界接口支持设置与查询接触频率、阻尼比和推开速度；柔度按子步长度计算，频率受步长上限约束，静态接触使用双倍频率。

持久接触可在相对平移和转角小于阈值时回收，复用锚点并更新分离；世界支持配置回收距离，刚体支持设置回收资格。过滤和几何变更仍清理旧接触。

接触摩擦按形状系数的几何平均混合，切向冲量受法向冲量的库仑界限限制，并参与热启动和持久缓存；形状支持设置与查询摩擦系数。

滚动阻力按最大形状半径缩放，角冲量受接触法向总冲量限制；按法向、滚动、切向顺序耦合求解，并参与热启动和缓存写回。

材质的切向目标速度相加后作用于摩擦约束，可实现传送带运动；形状支持读取与更新整体表面材质，包含负向目标速度。

弹性恢复使用两侧恢复系数的最大值，采样入射法向速度并按压缩冲量与 Poisson 能量额度限制反弹；形状支持设置与查询恢复系数。

世界支持设置与查询反弹速度阈值；入射速度须严格超过阈值并有压缩冲量才触发恢复，避免低速接触反复反弹。

恢复阶段可设置迭代次数并启用传播，按溢出色再普通色的顺序迭代；仅在存在恢复接触时运行，传播可将响应传递到零恢复系数接触。

世界支持自定义摩擦和恢复系数混合回调，回调接收两侧系数及 64 位用户材质 ID；清除回调恢复默认混合。形状支持设置与查询用户材质 ID。

刚体可锁定世界 x/y 平移和 z 旋转；运行时设置同步状态并重新计算质量，锁定作为位置积分前的最后约束，避免沿锁轴推进。

刚体支持运行时启用和禁用。禁用移除接触、代理与岛归属并保留几何和句柄，启用按类型恢复求解集合、代理与岛。

休眠同时观察真实速度和位姿修正速度，达到持续静止时间后整岛迁入休眠集合并移除活动状态与约束图占位；显式唤醒和非零速度会恢复整岛及触碰接触。

刚体可显式唤醒接触邻居；销毁触碰接触会唤醒两侧所在集合，移除休眠支撑后相关刚体恢复运动。

刚体支持配置休眠速度阈值和休眠许可，世界可整体开启或关闭休眠；关闭许可会唤醒相应集合，重新开启后可再次进入休眠。

推测接触允许在小正分离距离内建立约束，用距离除以子步时长限制靠近速度；慢速仍可自由靠近，无压缩冲量时不产生切向阻力，距离阈值外不生成接触点。

动态体对静态障碍支持连续碰撞：依据位移、转角和形状尺度选择快体，在局部重定心坐标中求最早撞击时刻并裁剪推进，随后同步代理。

快速子弹在普通刚体推进后单独扫掠静态、运动学与动态树，按最早撞击裁剪并同步代理；子弹之间跳过扫掠，刚体支持运行时设置与查询子弹标记。

刚体安全系数控制连续碰撞快体判定，世界支持设置最大线速度；位置积分前按线速度和每帧最大转角限速，快速旋转许可可绕过角速度上限，本帧限速标志在下一帧清理。

世界支持运行时设置与查询重力向量，后续步进立即采用新值，并继续遵守刚体重力缩放和运动类型语义。

世界热启动和连续碰撞可在运行时独立开关；连续碰撞开关同时控制普通快体和子弹扫掠，锁定世界期间不会更改设置。

世界可查询真实对象、接触、岛、活动接触、约束颜色、树高度及回收接触计数，也可查询步进观察到的容量高水位、临时栈高水位和分配字节数。

世界性能查询返回最近一步各已执行阶段的实际毫秒耗时；内存统计 API 可将当前世界各类容器、树、求解集合和栈容量导出到 box2d_memory.txt。

世界在有效步进后提供刚体移动事件数组，包含最终变换、刚体 ID、用户数据和本步入眠标记；下一次有效步进清空并重建缓冲，CCD 裁剪会同步事件位姿。

形状和刚体可为新接触启用开始/结束事件；触碰状态每次进入或退出只报告一次，结束事件双缓冲可交付两次步进之间由销毁产生的退出，事件携带可验证的形状及接触 ID。

命中事件要求启用形状许可、接近速度超过阈值且有确认法向冲量；每个接触只选最快点，按接触 ID 顺序输出世界点、法线、接近速度及可验证句柄。

传感器使用真实几何重叠与排序的双缓冲访客列表产生进入/退出事件，不加入接触约束；双方需允许传感器事件，快体扫掠可记录本帧穿过的传感器。

传感器参与许可可运行时开关，下一步产生相应进入/退出变化；传感器形状可查询排序的访客数量与带代数 ID 的重叠列表，查询按调用方容量截断。

形状可在定义中选择自定义碰撞过滤；世界回调收到形状 ID 和用户上下文，统一参与新接触候选、传感器重叠与连续碰撞查询，类别过滤仍先执行。

预求解回调可修改流形或清空接触点来拒绝响应，回调锚点按形状原点表示，之后再转换为质心锚点；启用预求解会停用对应接触回收，连续回调可拒绝撞击时刻。

世界 AABB 重叠查询接收相对原点与包围盒，查询静态、运动学、动态树并按双向类别掩码过滤，回调获得形状 ID，返回真实节点与叶访问统计。

世界形状重叠查询先检索代理包围盒，再在查询原点附近用带半径距离测试筛选真实重叠，支持旋转挂接形状并保持类别过滤与回调语义。

世界射线查询在查询原点附近对候选形状重新求交，回调可忽略、终止、按命中分数截断或继续；截断会传递到后续树，命中点和法线返回世界坐标。

最近射线查询 `b2World_CastRayClosest` 返回最近命中的形状、世界坐标、法线和分数，同时提供树遍历统计；未命中时 `hit` 为 false。

世界形状扫掠 `b2World_CastShape` 使用相对查询原点的凸形状代理，可按回调选择忽略、终止或截断；链段保留单侧碰撞约定。

`b2Shape_TestPoint` 对挂接形状执行世界坐标点包含查询，使用刚体当前变换；线段与链段返回 false。

`b2Shape_CastRay` 直接查询一个挂接形状，输入和命中点使用世界坐标，返回法线、分数及命中标记。

`b2Shape_GetClosestPoint` 以目标世界位置为查询点，使用当前几何及圆角半径求最近点，并返回世界位置。

`b2World_Explode` 按类别掩码选择动态形状，根据投影宽度计算冲量，并在指定衰减距离内降低作用；支持负值内爆。

`b2Shape_ApplyWind` 按形状的当前朝向和相对风速积累风阻、升力及力矩。休眠形状可按 `wake` 参数保持休眠或唤醒受力。

`b2SolvePlanes` 按碰撞平面迭代约束目标位移，记录各平面的推移，并支持有限推移上限产生软碰撞。

`b2ClipVector` 使用平面求解器记录的有效推移裁剪角色速度；离开表面的速度和禁止裁剪的软碰撞平面保持其原有作用。

`b2World_CastMover` 扫掠相对查询原点的胶囊，返回可移动分数。它使用角色贴面推进语义，并忽略初始重叠形状。

`b2World_CollideMover` 为胶囊收集世界接触平面，通过形状过滤器和回调选择需要的接触。平面可交给 `b2SolvePlanes` 与 `b2ClipVector` 处理位移和速度。

`b2World_GetBounds` 返回参与世界粗检测的形状边界并集；禁用形状不参与，空世界返回零边界。

`b2World_Draw` 通过用户回调输出当前世界的形状、接触、包围盒、质量和岛；`b2DefaultDebugDraw` 允许仅实现需要的回调。物理库继续独立构建，不需要图形窗口或渲染库。

`b2World_RebuildStaticTree` 可手动重建静态树，保留待处理的移动代理标志，以便后续步进继续发现接触。

关节对象使用带代数的 ID，并通过双向边挂接到两侧刚体；提供对象查询和刚体关节枚举，销毁刚体时同步移除附着的关节记录。

距离关节定义通过 `b2DefaultDistanceJointDef` 初始化。通用局部参考系从刚体原点测量；形状质量分布和质心变化不改变这一坐标约定。

关节连接参与持久岛、约束图着色和求解器集合管理。休眠及唤醒保留关节记录；禁用、启用和修改刚体类型会重新组织连接，静态刚体不桥接独立岛。

`b2CreateDistanceJoint` 创建两侧局部锚点之间的刚性距离约束，支持查询当前长度、调整静止长度，并参与每个子步的热启动和约束求解。创建时可选择连接刚体是否碰撞。

# Box2D

Box2D 是用于游戏的二维物理引擎。

## 当前能力

当前可以检查 C17 与 C++20 工具链，并用 CTest 运行测试。程序可以查询库版本 3.2.0 和双精度设置，也可以安装、触发并恢复断言回调，使用默认输出或用户日志回调记录消息，设置每米长度单位，以及按 64 字节对齐分配和释放内存。长度单位只接受有限正数，非法值保持原值。分配统计会在释放后回到原值，也可以换成自定义分配器。扩容时保留已有内容。清零分配得到全零内存，清零扩容只清零新增区间。可以判断浮点数是否为有限值，并计算整数与浮点数的最小、最大、绝对值和夹紧。二维向量支持加减、点积、叉积、长度和归一化。旋转可以组合、求逆，并保持单位长度条件。坐标变换支持点和向量在局部与世界之间往返。2×2 矩阵可以乘向量、求逆，并求解可逆与退化的线性方程。角度使用确定性的正弦、余弦、反正切和折返。动态数组带有 data、count、capacity，创建和销毁成对释放内存。容量可以预留和按两倍增长，已有内容保持不变。追加和原位追加在扩容前后都保留内容，也可以追加数组自身的元素。可以按下标读取元素，常量和非常量访问结果一致。尾部弹出按后进先出返回元素，剩余长度随之减少。交换删除会把末尾元素搬到被删位置，删除末尾时返回空索引。调整长度时缩小保留前缀，扩大保留已有值，清零调整会把范围内的元素写成零，清空只把长度归零并保留容量。创建、销毁和预留只接受平凡且标准布局的元素，元素对齐不超过 64 字节。值交换使用值临时变量，交换数组元素和指针时不会把同一侧的新值写回去。位集合可以创建和销毁，设定有效位数后可以设置、清除和读取指定位，范围外读取为假。失败断言的回调返回 0 时不会进入调试中断。它不提供物理模拟。

## 构建

需要 CMake 3.22 或更高版本，以及支持 C17 和 C++20 的编译器。

```powershell
cmake -S . -B build-core -G "Visual Studio 17 2022" -A x64
cmake --build build-core --config RelWithDebInfo --parallel 8
.\build-core\bin\RelWithDebInfo\toolchain_check.exe
ctest --test-dir build-core -C RelWithDebInfo --output-on-failure --no-tests=error
```

工具链程序通过时打印 `C17 and C++20 toolchain check passed` 并返回 0。CTest 会运行 `unit_tests`。

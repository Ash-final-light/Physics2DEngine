# Box2D

Box2D 是用于游戏的二维物理引擎。

## 当前能力

当前可以检查 C17 与 C++20 工具链，并用 CTest 运行测试。程序可以查询库版本 3.2.0 和双精度设置，也可以安装、触发并恢复断言回调，使用默认输出或用户日志回调记录消息，设置每米长度单位，以及按 64 字节对齐分配和释放内存。长度单位只接受有限正数，非法值保持原值。分配统计会在释放后回到原值，也可以换成自定义分配器。扩容时保留已有内容。清零分配得到全零内存，清零扩容只清零新增区间。可以判断浮点数是否为有限值，并计算整数与浮点数的最小、最大、绝对值和夹紧。二维向量支持加减、点积、叉积、长度和归一化。旋转可以组合、求逆，并保持单位长度条件。坐标变换支持点和向量在局部与世界之间往返。2×2 矩阵可以乘向量、求逆，并求解可逆与退化的线性方程。角度使用确定性的正弦、余弦、反正切和折返。动态数组带有 data、count、capacity，创建和销毁成对释放内存。容量可以预留和按两倍增长，已有内容保持不变。追加和原位追加在扩容前后都保留内容，也可以追加数组自身的元素。可以按下标读取元素，常量和非常量访问结果一致。尾部弹出按后进先出返回元素，剩余长度随之减少。交换删除会把末尾元素搬到被删位置，删除末尾时返回空索引。调整长度时缩小保留前缀，扩大保留已有值，清零调整会把范围内的元素写成零，清空只把长度归零并保留容量。创建、销毁和预留只接受平凡且标准布局的元素，元素对齐不超过 64 字节。值交换使用值临时变量，交换数组元素和指针时不会把同一侧的新值写回去。位集合可以创建和销毁，设定有效位数后可以设置、清除和读取指定位，范围外读取为假。扩容会保留已有位，并集把另一组相同长度的位并入当前集合。ID 池在空闲列表耗尽时发放新编号，释放后按后进先出复用，未释放的编号不会进入空闲列表。哈希集合的容量至少为 16 并向上取整到 2 的幂。插入已有键不会增加计数，哈希到同一槽的不同键沿探测链保存，两者都能找到。删除探测链中间或跨越表尾的键后，其余键仍然可以找到，不存在的键删除失败且计数不变。计数达到容量的一半时容量翻倍，原有键在新表中仍然可以找到，重复插入不改变计数。临时栈按 64 字节对齐分配，必须以后进先出释放。放不下的请求改为单独堆分配，全部释放后高水位仍保留，空闲时按高水位的一点五倍扩大容量。可以读取系统时钟，并计算从某个计数值到当前时刻经过的毫秒数，也可以在读取后把计数值重置为当前时刻。轴对齐包围盒可以检查上下界是否有效，计算中心、半尺寸、重叠和并集。边界相接算重叠，上界小于下界或含有非有限值则无效。射线可以命中包围盒的边和角，给出法线、命中点和比例。起点在内部、方向平行且落在盒外、线段太短或长度为零时不命中。比例恰好为 1 的边界命中有效。圆由中心和半径表示，半径可以为 0，但不能为负或非有限值。线段由两个有限端点表示，两端重合仍然有效。胶囊由两个端点圆心和半径组成。两端重合或半径为 0 仍然有效，负半径和非有限端点无效。点集可以算出逆时针凸包。内部点、过近的重复点和边上的共线点不会留下，全部共线、少于 3 个点或超过 8 个点时得到空凸包。顺时针或共线的结果不能通过校验。失败断言的回调返回 0 时不会进入调试中断。它不提供物理模拟。

## 构建

需要 CMake 3.22 或更高版本，以及支持 C17 和 C++20 的编译器。

```powershell
cmake -S . -B build-core -G "Visual Studio 17 2022" -A x64
cmake --build build-core --config RelWithDebInfo --parallel 8
.\build-core\bin\RelWithDebInfo\toolchain_check.exe
ctest --test-dir build-core -C RelWithDebInfo --output-on-failure --no-tests=error
```

工具链程序通过时打印 `C17 and C++20 toolchain check passed` 并返回 0。CTest 会运行 `unit_tests`。

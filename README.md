Box2D 是用于游戏的二维物理引擎。

## 当前能力

当前可以检查 C17 与 C++20 工具链，并用 CTest 运行测试。程序可以查询库版本 3.2.0 和双精度设置，也可以安装、触发并恢复断言回调，使用默认输出或用户日志回调记录消息，设置每米长度单位，以及按 64 字节对齐分配和释放内存。长度单位只接受有限正数，非法值保持原值。分配统计会在释放后回到原值，也可以换成自定义分配器。扩容时保留已有内容。清零分配得到全零内存，清零扩容只清零新增区间。可以判断浮点数是否为有限值，并计算整数与浮点数的最小、最大、绝对值和夹紧。二维向量支持加减、点积、叉积、长度和归一化。旋转可以组合、求逆，并保持单位长度条件。坐标变换支持点和向量在局部与世界之间往返。2×2 矩阵可以乘向量、求逆，并求解可逆与退化的线性方程。角度使用确定性的正弦、余弦、反正切和折返。动态数组带有 data、count、capacity，创建和销毁成对释放内存。容量可以预留和按两倍增长，已有内容保持不变。追加和原位追加在扩容前后都保留内容，也可以追加数组自身的元素。可以按下标读取元素，常量和非常量访问结果一致。尾部弹出按后进先出返回元素，剩余长度随之减少。交换删除会把末尾元素搬到被删位置，删除末尾时返回空索引。调整长度时缩小保留前缀，扩大保留已有值，清零调整会把范围内的元素写成零，清空只把长度归零并保留容量。创建、销毁和预留只接受平凡且标准布局的元素，元素对齐不超过 64 字节。值交换使用值临时变量，交换数组元素和指针时不会把同一侧的新值写回去。位集合可以创建和销毁，设定有效位数后可以设置、清除和读取指定位，范围外读取为假。扩容会保留已有位，并集把另一组相同长度的位并入当前集合。ID 池在空闲列表耗尽时发放新编号，释放后按后进先出复用，未释放的编号不会进入空闲列表。哈希集合的容量至少为 16 并向上取整到 2 的幂。插入已有键不会增加计数，哈希到同一槽的不同键沿探测链保存，两者都能找到。删除探测链中间或跨越表尾的键后，其余键仍然可以找到，不存在的键删除失败且计数不变。计数达到容量的一半时容量翻倍，原有键在新表中仍然可以找到，重复插入不改变计数。临时栈按 64 字节对齐分配，必须以后进先出释放。放不下的请求改为单独堆分配，全部释放后高水位仍保留，空闲时按高水位的一点五倍扩大容量。可以读取系统时钟，并计算从某个计数值到当前时刻经过的毫秒数，也可以在读取后把计数值重置为当前时刻。轴对齐包围盒可以检查上下界是否有效，计算中心、半尺寸、重叠和并集。边界相接算重叠，上界小于下界或含有非有限值则无效。射线可以命中包围盒的边和角，给出法线、命中点和比例。起点在内部、方向平行且落在盒外、线段太短或长度为零时不命中。比例恰好为 1 的边界命中有效。圆由中心和半径表示，半径可以为 0，但不能为负或非有限值。线段由两个有限端点表示，两端重合仍然有效。胶囊由两个端点圆心和半径组成。两端重合或半径为 0 仍然有效，负半径和非有限端点无效。点集可以算出逆时针凸包。内部点、过近的重复点和边上的共线点不会留下，全部共线、少于 3 个点或超过 8 个点时得到空凸包。顺时针或共线的结果不能通过校验。凸包可以做成多边形，复制顶点、写出外侧法线并计算质心。盒子和正方形是原点处的基本凸形状。空凸包会得到边长为 1 的正方形。多边形可以平移和旋转，圆角只增加半径、不改顶点。旋转后外侧法线跟着转动，质心落在变换后的位置。空凸包做偏移时仍得到原点处的单位正方形。圆的质量等于密度乘以面积，质心在圆心，绕质心的转动惯量是质量乘以半径平方的一半。胶囊质量由两端圆和中间矩形组成，质心在两端中点，两端重合时结果与同半径的圆一致。多边形质量由三角形积分得到，平移后质量与绕质心的惯量不变、质心跟着移动。单顶点和双顶点分别按圆和胶囊计算，圆角会增大质量。圆、胶囊、多边形和线段可以在给定变换下算出包围盒，多边形半径会把盒子向外扩大。点在圆内、圆上或圆外可以区分，半径为零时只有圆心算在里面。胶囊的中段和两端半圆都参与包含判断，两端重合时与同半径的圆一致。凸多边形在边界上算包含，平移和旋转后仍按变换后的边判断。圆角沿边向外扩展，对角顶点外侧要按到顶点的距离判断。射线与圆相交时给出命中点、外向法线和沿位移的比例。射线打不中、比例不够或从圆外发出的零长度射线都不命中；起点已经在圆内则记为命中。胶囊射线可以打中侧面或任一端帽，两端重合时与圆的结果一致，从内部发出时停在起点。线段射线可以只接受正面，也可以两面都接受。交点落在端点上算命中，超出端点、平行或打到重合端点的线段则不命中。半径为零的多边形射线会给出进入的边、法线和比例；打不中时没有交点，起点已经在多边形内则停在起点。两条线段可以求最近点：相交时距离为零，平行时保持间距，最近点会夹在端点上，退化成点时退回点到线段的距离。距离代理保存一份点的副本和半径，超过 8 个点时只保留前 8 个。带偏移的代理会先平移和旋转这些点。两个凸形状可以用 GJK 求最近点和距离。第二次查询可以复用上一次的单纯形缓存。形状重叠时距离为零。打开半径后，距离会减去两边的半径，最近点落在圆周上。形状 B 的位姿会先变到形状 A 的坐标系里。形状可以沿直线扫掠。相向移动时给出命中比例和法线，背向移动或比例不够时不命中。一开始就重叠时命中比例为零。圆、胶囊、线段和多边形都可以作为被扫掠的目标，各自把几何交给同一次形状扫掠。扫掠变换按时间插值质心和旋转，并把位置从质心移回局部中心。两个运动形状可以求出首次碰撞时间。相向移动时给出命中时刻和法线，背向离开时保持分离，一开始就重叠时时刻为零。两个圆在穿透、刚好接触和轻微分离时生成一个接触点，法线从第一个圆指向第二个圆。分离超过预测距离时没有接触点。胶囊与圆的接触会落在中段或某一端帽上，远离时没有接触点。多边形与圆可以在边上、顶点上或圆角外接触，圆心在多边形内时分离量为负，离得够远时没有接触点。两条平行胶囊在重叠的一侧给出两个接触点，端点相对时给出一个接触点，离得够远时没有接触点。线段与圆两侧都能接触，端点外按到端点的距离计算，离得够远时没有接触点。线段与胶囊在两侧重叠时各给出两个接触点，端点相对时给出一个接触点，离得够远时没有接触点。多边形与胶囊在边上给出两个带特征标识的接触点，靠近端点时仍有接触，带圆角时把半径算进分离量，离得够远时没有接触点。两个多边形边对边重叠时给出两个接触点，特征标识不同且重复计算保持不变，圆角计入分离量，离得够远时没有接触点。线段穿过多边形时分离量为负，离得够远时没有接触点。链段只在右侧与圆接触，落在相邻边区域内或离得够远时没有接触点，转角外侧仍由当前链段负责。链段与胶囊同样只在右侧接触，下一段负责的一侧没有接触点，当前段的端点附近仍有接触。链段与多边形在平滑连接处保持边法线，凸角外侧的幽灵碰撞会被丢掉，背面没有接触点。相邻多边形可以焊成闭合链条，共享边会抵消，T 形连接并进外轮廓，角点相触和完全重叠会标出状态，释放后链条内存成对归还。空的动态树可以创建和销毁，销毁后分配字节数回到创建前，销毁空指针没有影响。插入代理后可以读回包围盒和用户数据，已有代理的数据保持不变。删除一个代理后其余代理仍然有效，空出的编号会再次发给新代理，全部删除后计数回到零。移动代理会换成新的包围盒，扩大代理会改成更大的范围，旁边的代理保持原样。每个代理有自己的类别位，修改一个不会改到另一个。重建之后代理数量、包围盒和用户数据保持不变，父子包围盒仍然包含子节点。标记移动的代理可以被收集出来，重拟合之后根包围盒包住新的范围。包围盒查询的命中与逐个比较一致，类别掩码可以排除不匹配的代理。射线查询命中最近的包围盒，结果与逐个求交一致，打不中时没有代理。包围盒扫掠命中最近的代理，分数与扩大后的求交一致，扫空时没有代理。树可以报告高度、面积比、根包围盒和实际占用的字节数。可以创建和销毁空世界，非法重力不会占用世界槽，销毁后分配回到原值。空编号、越界编号和已销毁编号都无效，槽位复用后旧编号仍然无效。世界用户数据可以写入并读回，另一个世界不受影响。可以按默认定义创建和销毁刚体，非法位置不会占用槽位，世界销毁后分配回到原值。刚体槽位复用后旧编号仍然无效，销毁世界后该编号也无效。刚体名称最长 10 个字符，用户数据可以写入并读回，另一个刚体不受影响。失败断言的回调返回 0 时不会进入调试中断。它不提供物理模拟。

## 刚体姿态

可以读取刚体位置、旋转和世界变换，并在局部与世界坐标之间转换点和向量。点转换包含平移，向量转换只包含旋转。可以设置刚体的位置和旋转；非法输入保持原状态，后续查询立即反映有效变换。

刚体可以挂接和销毁圆形、胶囊、多边形、线段，形状使用独立且可复用的稳定编号。包围盒合并已挂接形状的预测性范围；没有形状时返回包住刚体原点的零尺寸范围。修改变换会同步形状范围，销毁刚体会销毁其全部形状。质量读写、传感器、碰撞和步进尚未接入。

形状用户数据可以在创建时写入，也可以独立设置和查询；过期形状编号不会改到复用后的对象。

可以读取形状类型和几何数据，并在圆、胶囊、多边形与线段之间修改几何。修改保留形状编号和用户数据，包围盒立即更新。

## 构建

需要 CMake 3.22 或更高版本，以及支持 C17 和 C++20 的编译器。

```powershell
cmake -S . -B build-core -G "Visual Studio 17 2022" -A x64
cmake --build build-core --config RelWithDebInfo --parallel 8
.\build-core\bin\RelWithDebInfo\toolchain_check.exe
ctest --test-dir build-core -C RelWithDebInfo --output-on-failure --no-tests=error
```

工具链程序通过时打印 `C17 and C++20 toolchain check passed` 并返回 0。CTest 会运行 `unit_tests`。
